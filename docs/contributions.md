# 个人研究与工程工作

## 方法研究与论文代码复现

研究肌肉协同运动决策、仿生阻抗控制和抓握分类，梳理离散类别、多标签组合与连续运动回归的任务区别。分析CNN/CNN-LSTM公开项目中的数据构造、训练和后处理。

实际复现工作包括MATLAB项目目录与路径适配、用户目录枚举、模型和结果保存、信号补齐边界、CPU/GPU运行适配，以及CNN重新训练与5用户小规模测试。CNN-LSTM目前按方法和源码分析、运行适配列示；不将其重新训练或论文整机结果计入已完成成果。

## 模型训练与系统化优化

在既有CNN-Transformer框架上增加窗口来源元信息、文件级分组验证、稳健MVC归一化、幅值裁剪、正类加权BCE和逐标签阈值搜索。围绕预处理、优化器和结构开关开展因素拆分、组合消融及三个随机种子复核，筛选阶段性候选。

## 实验范式与对照研究

参与将协同条件与单标签条件的比较问题转化为可核对的实验约束：共同骨干、任务适配的输出与损失、匹配采集和调参预算、分组划分、校准与投票规则。研究抓型、目标物体、类别和设备指令的关系。

## 实验工具与软件工程

开发校准与MVC流程、可复现任务计划、实验状态机、类别映射、单标签解码、标注训练衔接和事件记录。修复约束随机排程的贪心死路，增加归一化输入校验和训练配置一致性检查。

## 数据质量与特征构建

围绕已有肌电和手套记录核查完整性、重复试次、工频干扰、时序与标定；构建单向滤波和因果RMS特征，分析静息漂移、标签裁剪失真与位置差分问题，保留原始记录与派生产物的追溯关系。

## 上位机与嵌入式联调

开发实时波形、手势提示、暂停恢复、坏动作标记、重做保留和会话保存；处理串口半包、粘包、超时与并发写盘。推进STM32、RS-485、快照缓存和DMA遥测链路调试，并完成本人肌电采集、个体化模型训练、模型加载与机械手在线动作验证。
